# البنك المركزي العراقي — تطبيق الخدمات الذاتية للموارد البشرية (CBI HR Portal)

تطبيق رسمي آمن مخصص لموظفي البنك المركزي العراقي (Central Bank of Iraq) للوصول إلى الملف الوظيفي، بيانات الخدمة، والخدمات الذاتية للموارد البشرية، مع دعم تسجيل الدخول الموحد عبر Microsoft Entra ID وتقنية مفاتيح المرور البيومترية (Passkeys / FIDO2).

---

## 🏛️ المميزات الرئيسية

- **المصادقة المتطورة بدون كلمات مرور (FIDO2 / Passkeys)**: تسجيل دخول فوري وآمن عبر البصمة والوجه دون الحاجة لكتابة كلمات المرور.
- **تسجيل الدخول المؤسسي (Microsoft Entra ID)**: تكامل كامل مع حسابات المؤسسة عبر OIDC مع بروتوكول PKCE.
- **الملف الوظيفي الشامل**: استعراض معلومات الموظف، التشكيل الإداري، الرتبة والمرحلة، المؤهلات العلمية، وتاريخ التعيين والترقية.
- **الخدمات الذاتية للموظف**: دليل تفاعلي للخدمات الإلكترونية والإدارية.
- **إدارة الأجهزة ومفاتيح الأمان**: إمكانية تسجيل وحذف مفاتيح المرور المرتبطة بالحساب واستعراض تفاصيل الجهاز النشط.
